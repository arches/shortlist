# Shortlist

Shortlist keeps track of restaurants you want to visit, and what you thought of the ones you have been to.

## A companion project for Alloy

Shortlist is the worked example for [Alloy](https://github.com/arches/alloy), a catalog of techniques for describing software systems and a set of Claude Code skills that turn those descriptions into code.

Alloy artifacts live in `/docs`: the glossary, the data model, the principles, the diagrams, etc. Those artifacts are the specification. The code under `api/` and `frontend/` is generated from them in separate sessions, so a decision that matters is recorded in an artifact rather than in a conversation.

Zero manual edits are made to any code, including via vibe coding. The only information used to generate the code lives in the artifacts.

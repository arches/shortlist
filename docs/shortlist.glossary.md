# Shortlist Glossary

The naming authority for Shortlist. Identifiers in code come from the **Term** column. A name used in another artifact in a sense the definition does not support is a defect in that artifact.

**Not to be confused with** lists names that have been used _as_ this term. A word appearing there is not banned from the prose — it is a defect only where it stands in for the term. "One occasion of eating at a Restaurant" is ordinary English; "the occasion is added to the restaurant's history" is the alias the column exists to catch.

This holds only the terms that have actually been got wrong. Most nouns in the system are absent because nobody has argued about them.

| Term           | Definition                                                                          | Not to be confused with                                                                                                                           |
| -------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Experience** | One occasion of eating at a Restaurant, carrying what the owner thought of it.      | Visit, review, check-in, occasion.                                                                                                                |
| **List**       | A group of restaurants a User has created                                           | **Shortlist**, which is the app                                                                                                                   |
| **Rating**     | How many stars the owner gave one Experience: 1 to 5, in half-star steps.           | A rating of a Restaurant - there is no such thing. Also not a score out of ten, and not an average across Experiences.                            |
| **Restaurant** | A wrapper for a Google Place                                                        | Place, venue, listing                                                                                                                             |
| **Session**    | The stretch between one sign-in and the sign-out, expiry or revocation that ends it | **Refresh token**, which is one row enabling one device to continue a Session. Also not the **access token** a request carries, and not a cookie. |
| **Shortlist**  | The name of the app.                                                                | List                                                                                                                                              |
| **Visited**    | A restaurant for which the user has an experience.                                  |                                                                                                                                                   |
